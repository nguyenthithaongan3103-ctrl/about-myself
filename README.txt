WEBSITE GIỚI THIỆU BẢN THÂN BÉ NGÂN

CÁCH ĐĂNG LÊN GITHUB PAGES
1. Tải file ZIP và giải nén.
2. Mở repository GitHub của website bà muốn dùng.
3. Chọn Add file > Upload files.
4. Kéo 3 file index.html, style.css, script.js vào thư mục gốc repository (đặt cùng cấp nhau).
5. Kéo xuống cuối trang, bấm Commit changes.
6. Chờ 1–3 phút rồi mở website và nhấn Ctrl + F5.

LƯU Ý
- Đây là website tĩnh, không cần cài thêm phần mềm.
- Ảnh hiện là khung trang trí; có thể thay bằng ảnh thật sau.
- Playlist dẫn đến tìm kiếm YouTube, không tự phát nhạc.
- Font Google cần Internet; nếu không có mạng, trang vẫn hoạt động với font dự phòng.

CHỈNH SỬA
- Nội dung: index.html
- Màu sắc, giao diện: style.css
- Menu và hiệu ứng cuộn: script.js
